# Pianificatore turni

Esempio Python didattico che genera una pianificazione settimanale a partire da disponibilità e ore richieste per ogni persona. Lo script assegna turni ipotetici di otto ore e stampa il risultato in console.

## Esecuzione

```bash
python pianificatore.py
```

## Stato

Script dimostrativo: team, disponibilità e orari sono dati statici nel file sorgente.
